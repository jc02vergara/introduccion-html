# Página Web Personal - Introducción a HTML

Proyecto de la tarea "Introducción a HTML".

## Descripción

Página web personal de **Jean Carlo Vergara** creada con **HTML** y **CSS**, con estética *Y2K Desktop Interface* (fondo morado cuadriculado y ventanas flotantes). Muestra información personal (sobre mí, habilidades, experiencia laboral, educación, certificaciones y contacto). Además incluye una **calculadora en PHP** que realiza operaciones básicas (suma, resta, multiplicación y división).

## Estructura del proyecto

```
introduccion-html/
├── index.html                          # Página personal principal (estética Y2K)
├── style.css                           # Estilos CSS (fondo morado, ventanas, taskbar)
├── calculadora.php                     # Calculadora en PHP
├── README.md                           # Este archivo
└── Entrega_Tarea_Introduccion_HTML.pdf # Informe en formato APA
```

## Requisitos

- Navegador web moderno.
- Servidor con soporte PHP (XAMPP, WAMP, Laragon) para ejecutar la calculadora.

## Cómo ejecutar

1. Clona el repositorio:
   ```bash
   git clone https://github.com/jc02vergara/introduccion-html.git
   ```
2. Abre `index.html` en el navegador para ver la página personal.
3. Para usar la calculadora, sirve los archivos con un servidor PHP y accede a `calculadora.php`.

> **Nota:** La calculadora en PHP no se ejecuta en GitHub, ya que GitHub Pages y la vista previa de archivos solo sirven contenido estático (frontend: HTML, CSS y JavaScript). PHP requiere un servidor con intérprete PHP. Por eso, para probarla es necesario un entorno local con PHP habilitado.
