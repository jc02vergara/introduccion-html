# Página Web Personal - Introducción a HTML

Proyecto de la tarea "Introducción a HTML".

## Descripción

Página web personal creada con **HTML** y **CSS**, que muestra información personal (sobre mí, habilidades y contacto). Además incluye una **calculadora en PHP** que realiza operaciones básicas (suma, resta, multiplicación y división).

## Estructura del proyecto

```
introduccion-html/
├── index.html          # Página personal principal
├── style.css           # Estilos CSS
├── calculadora.php     # Calculadora en PHP
└── README.md           # Este archivo
```

## Requisitos

- Navegador web moderno.
- Servidor con soporte PHP (por ejemplo, XAMPP, WAMP, Laragon) para ejecutar la calculadora.

## Cómo ejecutar

1. Clona el repositorio:
   ```bash
   git clone <url-del-repositorio>
   ```
2. Abre `index.html` en el navegador para ver la página personal.
3. Para usar la calculadora, sirve los archivos con un servidor PHP y accede a `calculadora.php`.
